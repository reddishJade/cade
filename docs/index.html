01 — 核心能力Capabilities

把 coding agent 拆成
可测试、可扩展 的部件 Decompose a coding agent into
testable, extensible parts

01

结构化 Agent 循环与统一内核Structured Agent Loop & Unified Kernel

CodingAgentHarness 统一消费 provider 流式事件（文本、推理思考流、工具调用与结果），在单一可信循环中驱动 TUI、CLI 与 Web 三端工作台。CodingAgentHarness consumes streaming events — text, reasoning, tool_use, and tool_result — driving TUI, CLI, and Web interfaces from a single deterministic loop.

02

无损历史与动态投影 (/undo)Lossless History & Projections

会话以追加型不可篡改日志持久记录，任何历史状态均可投影视角。配合磁盘快照池，实现毫秒级原子文件回退与视窗回拨，决不静默截断。Sessions persist as append-only event logs with dynamic projections. Snapshot pooling enables atomic file reverts and window rewinds without silent truncation.

03

95% 无摘要换窗机制95% Summary-Free Context Rollover

彻底剔除模型自我递归摘要引起的信息失真与幻觉放大。在 95% 上下文容量阈值自动平滑重开窗口，继承核心目标并对冲中间冗余。Eliminates lossy self-summaries. Automatically rolls over context at 95% capacity, inheriting core goals while purging intermediate tool outputs.

04

按需 MemoryOn-Demand Memory

少量昂贵经验保存为 .cade/memory/ 内的可编辑 Markdown。Agent 按需搜索、读取历史来源并核验当前代码，普通 turn 和恢复不加载 Memory。A few costly findings live in editable workspace Markdown. Search on demand, follow history sources, and revalidate current code; ordinary turns and resume do not load Memory.

05

三种执行模式与权限沙箱Three Execution Modes & Sandboxing

plan 只读勘察防误改，build 交互开发（默认），act 全自动推进。结合工作区路径隔离、敏感命令审批与受限环境，守护系统安全。plan for read-only safety, build for guided development, act for automated sprints. Path jailing, policy gating, and sandboxing secure host environments.

06

三端工作台与扩展生态Tri-Workbenches & Ecosystem

默认 TUI 全屏分屏视图、极速 CLI 交互流与可视化 Web 端无缝切换；原生支持 MCP 外部工具协议集成与 Python 生命周期 Hooks 自动化。Seamlessly switch between split-pane TUI (default), CLI streams, and Web interfaces; with native MCP protocol integration and lifecycle hooks.

02 — 快速开始Quick Start

克隆、安装、直接对话 Clone, install, start talking

1

安装 CadeInstall Cade

使用 uv tool install 安装（Linux 默认沙箱需要 bubblewrap / bwrap）。Install the command-line tool with uv (Linux default sandbox requires bubblewrap / bwrap).

2

配置 ProviderConfigure a provider

首次运行 cade，选择账户登录或 API key 并配置模型。Run cade to choose account sign-in or an API key and configure a model.

3

启动会话Launch a session

默认进入 TUI；cli 进入 REPL；-p 直接提问。cade -c 继续最近任务；--resume 选择历史会话。Default launches TUI; cli enters REPL; -p asks a single question. cade -c continues the latest task; --resume picks a previous session.

沙箱与安全：Linux 下 Agent 的 bash 命令默认在 bubblewrap 沙箱中运行（工作区与 /tmp 可写、宿主其余路径只读、凭据遮蔽、网络隔离）；权限引擎与自动 reviewer 负责操作审批。 Sandbox & Safety: On Linux, agent bash commands run inside a bubblewrap sandbox by default (writable workspace & /tmp, read-only host, credential masking, network isolation); the permission engine and auto-reviewer handle operation approvals.

Shell 
uv tool install --python 3.12 git+https://github.com/reddishJade/cade.git
cd /path/to/your/project

cade                # 默认：启动 TUI 沉浸式工作台# Default: launch TUI workbench
cade cli            # 启动命令行 REPL 模式# Launch interactive CLI REPL
cade web            # 启动现代 Web 浏览器工作台# Launch browser workbench (FastAPI + WebSockets)
cade -c             # 极速断点续接最近任务# Resume latest task
cade (TUI) cade cli cade web cade -c cade -p "..." cade config

03 — 实战场景Workflows

你可以用 Cade 做什么 What you can do with Cade

>_

勘察与理解代码库Understand your codebase

利用只读并发调度快速检索符号、分析目录结构，或使用 @file 注入精准上下文，快速理清复杂系统。Search symbols, map dependencies with concurrent reads, or inject exact context with @file to grok unfamiliar systems.

⚑

Plan 规划与 Build 实施Plan and build features

在 /plan 模式下零副作用产出架构方案与文件清单；切换至 /build 模式由沙箱与审查器守卫全自动落地。Produce zero-side-effect plans in /plan mode, then switch to /build mode to implement features safely under sandbox gating.

⎇

会话分支与快照撤销Branching and snapshot undo

大胆尝试实验性重构；随时用 /fork 开启新分支探索，或用 /undo 瞬间原子回滚所有受影响的文件变更。Explore refactors freely; use /fork to branch off a previous turn, or /undo to atomically restore modified files.

⬡

连接 MCP 工具生态Extend with MCP tools

通过标准 MCP stdio 协议直连本地数据库、外部 API 或自定义服务，动态扩充 Agent 的专业工具箱。Plug into local databases, APIs, or custom servers via standard MCP stdio protocol with dynamic tool discovery.

◈

跨会话长期记忆Long-horizon memory

可复用经验留在 workspace Markdown，使用既有 bash + rg 按需搜索；来源只证明历史存在，使用前仍需核对当前代码。Keep reusable findings in workspace Markdown and search with existing bash + rg. Sources establish that history exists; current applicability still needs verification.

⚡

外部 Hooks 自动化Event-driven hooks

在工具调用前后挂载外部脚本，实现命令执行前的动态安全判定、代码生成后的自动格式化与审计通知。Attach external scripts before or after tool runs for dynamic policy gating, automatic formatting, or audit notifications.

事件驱动循环、Prompt 装配、95% 水位线无摘要平滑换窗引擎、工具并发安全分区、动态历史投影。Event-driven loop, prompt assembly, 95% summary-free context rollover engine, tool concurrency, and dynamic projection.
