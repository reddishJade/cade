01 — Capabilities

Decompose a coding agent into
testable, extensible parts

01

Structured agent loop and shared runtime

CodingAgentHarness consumes streaming events — text, reasoning, tool_use, and tool_result — driving TUI, CLI, and Web interfaces from a single deterministic loop.

02

History and projections

Sessions persist as append-only event logs with dynamic projections. Snapshots support per-file restoration; separate history commands change the active conversation branch.

03

Context rollover without summaries

Eliminates lossy self-summaries. Uses an effective input budget with a default ratio cap of 95% of the physical window. Rollover retains task state and references to original history.

04

On-demand memory

A few costly findings live in editable workspace Markdown. Search on demand, follow history sources, and revalidate current code; each request includes a catalog of up to 4 KiB with paths, titles, and opening hints. Full bodies are read on demand.

05

Execution modes and sandboxing

plan for read-only safety, build for guided development, act for automated sprints. Path jailing, policy gating, and sandboxing secure host environments.

06

Hosts and extensions

Seamlessly switch between inline transcript TUI (default), CLI streams, and Web interfaces; with native MCP protocol integration and lifecycle hooks.

02 — Quick Start

Clone, install, start talking

1

Install Cade

Install the command-line tool with uv (Linux default sandbox requires bubblewrap / bwrap).

2

Configure a provider

Run cade to choose account sign-in or an API key and configure a model.

3

Launch a session

Default launches TUI; exec runs automation; web opens the browser workbench. cade -c continues the latest task; --resume picks a previous session.

Sandbox & Safety: On Linux, agent bash commands run inside a bubblewrap sandbox by default (writable workspace & /tmp, read-only host, credential masking, network isolation); the permission engine and auto-reviewer handle operation approvals.

Shell 
uv tool install --python 3.12 git+https://github.com/reddishJade/cade.git
cd /path/to/your/project

cade                # 启动默认 TUI 工作台
cade tui            # 启动终端工作台
cade web            # 启动浏览器工作台
cade -c             # 继续最近的任务
cade (TUI) cade tui cade web cade -c cade exec "..." cade config

03 — Workflows

What you can do with Cade

>_

Understand your codebase

Search symbols, map dependencies with concurrent reads, or inject exact context with @file to grok unfamiliar systems.

⚑

Plan and build features

Produce zero-side-effect plans in /mode plan mode, then switch to /mode build mode to implement features safely under sandbox gating.

⎇

Branching and snapshot undo

Explore refactors freely; use /fork to branch off a previous turn, /undo to restore files with per-file checks, or /rewind to adjust conversation history.

⬡

Extend with MCP tools

Plug into local databases, APIs, or custom servers via standard MCP stdio protocol with dynamic tool discovery.

◈

Long-horizon memory

Keep reusable findings in workspace Markdown and search with existing bash + rg. Sources establish that history exists; current applicability still needs verification.

⚡

Event-driven hooks

Attach external scripts before or after tool runs for dynamic policy gating, automatic formatting, or audit notifications.

04 — TUI Commands

One slash to switch modes

/mode plan
Enter read-only planning mode
/mode build
Enter write-enabled build mode
/mode act
User approval mode (default)
/undo
File-level snapshot undo
/resume
Resume a past session
/fork
Branch a new session from a message
/model
Show or switch the current model
/memory
Show the Memory directory

See the full 30+ slash commands in the Docs or README.

05 — Architecture

Shared runtime, clear ownership

surfaces/

Host interfaces

Terminal workbench (default), exec automation, and Web browser workbench share a runtime and persistent sessions.

harness/

Runtime and harness assembly

App bootstrap, append-only lossless session storage, permission engine, audit logging, MCP protocol, and lifecycle hooks.

agent/

Agent loop and context

Event-driven loop, prompt assembly, budgeted context rollover engine, tool concurrency, and dynamic projection.

coding_agent/

Coding tools and sandbox

Atomic file patching, directory survey, subagent orchestration, and sandboxed safe execution.

ai/

AI provider adapters

Unified interface for DeepSeek, OpenAI, ChatGLM, MiMo, and local endpoints with streaming, prompt caching, and reasoning tokens.
