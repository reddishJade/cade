# Cade E2E 验收

## 适用范围

本技能用于执行 E2E（End-to-End，端到端）验收。先按[验证准则](../../../docs/testing.md)确认需要 E2E，再准备环境。运行前说明现有检查遗漏的风险，写清任务、预期结果和检查方法。

## 准备

每次使用独立的 `e2e-results/<run>/` 目录。工作区、配置、会话、缓存和日志都放在仓库内。创建目录前检查实际路径，避免覆盖已有文件。任务文件与验收证据分开存放。

按[配置与命令](references/run.md)准备本次配置。凭据由 Cade 从现有认证文件读取。保留全局配置，不复制或打印密钥和令牌。

## 运行

选择与风险对应的入口：

- exec：运行 `cade exec`，使用真实 provider 和服务。
- TUI：在终端中操作并检查界面。
- web：在浏览器中操作运行中的服务。

保留场景要求的审批、沙箱和网络限制。设置步骤数、模型调用次数和超时上限。保存事件、标准错误、退出码和会话记录。

## 检查结果

按预先写明的方法检查文件、工具结果和请求记录。模型的完成声明和退出码 0 不能单独证明任务成功。恢复场景用新进程续接同一会话；权限场景检查拒绝操作是否产生副作用。

配置或服务不符合要求时，记录原因并停止。连接失败时先查明原因，再决定是否重试。代码缺陷保留复现步骤，修复后重跑对应检查。

报告通过、失败或环境阻塞。列出有效配置、证据目录、检查结果和未覆盖的风险。保留失败记录，隐藏认证信息。未经要求，保留验收目录，不提交日志和临时工作区。
